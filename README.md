# Build Your Own Online Shop

An interactive, self-paced e-commerce lesson for business students.

- **Part 1:** from dot-com to AI. Covers e-commerce types, business models, Web 2.0 and channels, how online payments work, and AI.
- **Part 2:** build your own shop that takes test payments, using an AI assistant, Stripe, Supabase and Vercel.
- **Part 3:** what it takes to make it real. Covers finding customers, fulfilment, the law, security, and ethics.

The whole site is a single static page (`index.html`) plus the images in `shots/`. It needs no build step.

## Viewing it

Published with GitHub Pages. Locally, open `index.html` in a browser. The embedded YouTube videos only play when the page is served over http(s), not when it's opened as a file.
